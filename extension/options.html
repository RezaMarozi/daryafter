Daryafter extension

When on, clicking a link that points to a file type below (or any <a download> link) sends it to Daryafter instead of downloading it in the browser. For fully automatic downloads, also untick "Ask for the file name when a copied link is added" in Daryafter's Settings.

PDF is not on the list by default, so you can still read PDFs in the browser. Add it here if you want those downloads in Daryafter too.

Must match Daryafter's bridge port (default 27240). Normally you never need to change this.

The bridge only listens on 127.0.0.1 and rejects requests that do not come from this extension, so web pages cannot abuse it. In Firefox, if auto-download does nothing, open about:addons, this extension's "Permissions" tab and make sure "Access your data for all websites" is enabled (the content script needs it).
