Daryafter extension

Send downloads to the Daryafter download manager

When on, clicking a link that points to a file type below (or any <a download> link) sends it to Daryafter instead of downloading it in the browser. Ordinary navigation is never touched.

File types to auto-download

One per line. PDF is not on the list by default, so you can still read PDFs in the browser — add it here if you want those downloads in Daryafter too.

Connection

Must match Daryafter's bridge port (default 27240). Normally you never need to change this. The bridge only listens on 127.0.0.1 and rejects requests that do not come from this extension, so web pages cannot abuse it.

If Daryafter is not running, this extension starts it for you through the native messaging host — installed system-wide by the daryafter package (Firefox), or run native-host/install.sh for a user-level registration. In Firefox, if auto-download does nothing, open about:addons > this extension > Permissions and enable “Access your data for all websites”.
