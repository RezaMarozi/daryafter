Daryafter extension

Send downloads to the Daryafter download manager

Downloads

Choose what the extension hands to Daryafter.

When on, clicking a link that points to a file type below (or any <a download> link) sends it to Daryafter instead of downloading it in the browser. Ordinary navigation is never touched.

One per line (commas also work). PDF is not on the list by default, so you can still read PDFs in the browser — add it here if you want those downloads in Daryafter too.

Connection

The extension talks to a loopback-only bridge inside Daryafter.

Must match Daryafter's bridge port (default 27240). You normally never need to change this.

Checking…

The bridge only listens on 127.0.0.1 and rejects requests that do not come from this extension, so web pages cannot abuse it.

Save changes

Settings are stored in this browser profile.

If Daryafter is not running, the extension asks the native messaging host to start it. The host is installed system-wide by the daryafter package (Firefox); for Chrome/Chromium run native-host/install.sh with CHROME_ID set to this extension's ID. In Firefox, if auto-download does nothing, open about:addons > this extension > Permissions and enable “Access your data for all websites”.
